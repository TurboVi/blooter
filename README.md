# Light On Website

نسخة مبسطة من موقع Light On.

## التشغيل
افتح `index.html` مباشرة بالمتصفح.

ولتشغيله كسيرفر محلي:
`python -m http.server 8080`

ثم افتح:
`http://localhost:8080`
